# Forge v1.2.42

## What changes for client repos

- The session-start hook is fast again (issue 1653). It prints at most three "keeps breaking" lines and a pointer to `forge next`, and it makes no network call and no GitHub call. On a large repo it went from 78 seconds to under 2 seconds, so Claude worker rounds no longer time out at start. Nothing to do.
- `forge land --all` lists an item under Merged only when its pull request has merged (issue 1638). Before, a fix round handed to a Claude helper could show as merged. In repos where the agent merges, such an item now waits under Needs you, with the real reason. Read that reason before you act.
- `forge upgrade` also updates Claude Code and the Codex CLI to their latest versions. It uses the installer that installed each one, prints the version it installed, and prints a line to run by hand when an update needs sudo or cannot run. `forge sync` does not touch them. Run the printed line yourself when there is one.
- New TypeScript and Python starter apps check their types with TypeScript 7, the native compiler. Existing apps keep their setup.
- The starter's browser motion test waits for animations to finish instead of a fixed 100 ms, so it no longer fails by chance. Nothing to do.

## Known issues

- **The first upgrade to v1.2.42 runs the previous release's upgrade code.** So that upgrade does not update Claude Code or the Codex CLI. Every later upgrade does. Workaround: update them by hand once.
- **An old Codex from OpenAI's standalone installer is not updated.** Forge prints the install line instead of updating it. Workaround: run the printed install line.
