# Short model names pick the newest model at each run

<n> parts · Risks: ... · New moving parts: ...

## What changes for you

- forge.toml can name a model in short form (sol, astra, terra or luna for Codex; sonnet, opus or haiku for Claude), and Forge uses the newest model of that name that the installed tool offers, checked at the start of each build, review or read.
- Full model names such as gpt-6.1-terra keep working exactly as written.
- Each round shows the exact model it used. If the installed tool has no model of that name, the round stops with one line that lists the models it does have.
- New repos start with short names, so they get the newest models. Existing repos keep their current model names until their owner edits them.

## Why

Forge's defaults and client settings name fixed model versions, so a newer model needs a new Forge release and a manual edit in every client repo.

## Done when

1. **A new repo's forge.toml uses short names. A round shows the exact model it used. A short name with no matching model in the installed tool stops the round with one line listing the models that tool offers.**
